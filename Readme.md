# LETS — Recycled-Paper Pencil

### Product Development & Go-to-Market Case Study

> **Building an affordable, sustainable alternative to conventional wooden pencils through recycled-paper manufacturing, product innovation, and scalable distribution.**

---

## 📌 Overview

**LETS** is a recycled-paper pencil concept designed to deliver the familiar functionality of a conventional pencil while replacing the traditional wooden body with recycled paper.

The project explores how a sustainable stationery product can combine:

* ♻️ **Sustainability**
* ✏️ **Everyday writing performance**
* 💰 **Affordability**
* 🎨 **Design & customization**
* 🏭 **Scalable manufacturing**

The long-term objective is to make sustainable stationery accessible to a mass-market audience without requiring customers to change their existing pencil usage habits.

---

## 🎯 Problem

Conventional pencils are a familiar, low-cost stationery product, but their traditional wooden construction creates an opportunity to explore more sustainable alternatives.

The challenge is not simply to create an eco-friendly pencil.

The real product challenge is:

> **Can a recycled-paper pencil deliver a conventional-pencil experience while remaining affordable, scalable, and commercially viable?**

LETS addresses this challenge through recycled-paper construction, prototype development, process optimization, and a planned wholesaler-to-retailer distribution model.

## 💰 Unit Economics

Current prototype-level economics:

| Metric                           |              Value |
| -------------------------------- | -----------------: |
| Current production cost          | **₹1.50 / pencil** |
| LETS → Wholesaler                | **₹3.00 / pencil** |
| Wholesaler → Retailer            | **₹3.80 / pencil** |
| Gross profit at wholesaler price | **₹1.50 / pencil** |
| Gross margin at wholesaler price |            **50%** |

### Important Assumption

The ₹1.50 production cost represents the current prototype-level cost.

Commercial-scale economics would require further validation of:

* Raw materials
* Labour
* Machinery
* Packaging
* Transportation
* Production wastage
* Maintenance
* Distribution costs
